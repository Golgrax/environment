### VERSION 0.0.0

We have decided to transition from a standard Node.JS repository library into a full polyglot mono-repository, which will allow us to publish this library to different language ecosystems, such as; Rust (crates.io), Python (PyPI), Go (Go Modules), TypeScript (npm), PowerShell (PSGallery), and C# (NuGet).

The old changelogs have been deleted but are still visible through the GitHub commit history: https://github.com/octovel/environment-node/commit/0261cec7cdf4fb7912422eea3ba529b79e7ed35a

## Additions

- Added a new repository structure to support multiple languages and ecosystems.
- Added a `VERSION` file to represent the current version of the mono-repository.
- Reworked the `SUPPORT.md` documentation file.
- Reworked the `SECURITY.md` documentation file.

## Deprecations

- Temporarily archived the Node.JS implementation documentation.
- Temporarily archived the Node.JS implementation source code.
- Temporarily archived the Node.JS implementation examples.
