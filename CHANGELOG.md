### 0.0.1-canary.1 : Initial Release

GitHub release: https://github.com/octovel/environment-node/releases/tag/v0.0.1-canary.1
NPM release: https://www.npmjs.com/package/@octovel/environment

## Changes:
- Added `SystemEnvironment` class for managing system-wide environment variables.
- Added `UserEnvironment` class for managing user-specific environment variables.
** **
- Added `ProcessMonitor` class for monitoring system processes.
- Added `ProcessManager` class for managing the system environment.
- Added `ProcessRegistry` class for managing the system process registry.
- Added `ProcessController` class for controlling system processes.
** **
- Updated README.md to include information about the library's types and classes, and provided classes through the API.
- Updated the documentation to include detailed information about each class and its methods.
- Updated the examples to demonstrate how to use each class and its methods.
