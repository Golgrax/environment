# Environment

Environment is a polyglot monorepository with the goal of offering a unified, type-safe, and consistent API for a variety of programming languages. This allows developers to work with the system, user, and process environment on any platform with ease.

In order to ensure dependability, maintainability, and cross-language compatibility, this project seeks to provide a standardized developer experience across ecosystems such as Node.js, Python, Go, Rust, C#, and PowerShell.

---

## Status

As of right now, this repository is being transformed into a [monorepository](https://en.wikipedia.org/wiki/Monorepo) and is **under active development**.

Whether it's a new language implementation, an issue report, or an improvement to the API design, suggestions, ideas, and feedback are greatly appreciated.

A full documentation site with tutorials, examples, and API references will be made available to the public once the project is ready:

[https://octovel.github.io/environment](Octovel.github.io/environment)
